# AIAA 3102 Final Project Grading Rubric (40 Points)

Dear students,

The final project will be graded according to the following rubric, with a total of **40 points**.

## 1. Performance (12 Points)

The classification performance of the SuperAgent will be evaluated on three tasks, each worth 4 points.

| Task            | Maximum Points |
| --------------- | -------------- |
| Released Task 1 | 4              |
| Released Task 2 | 4              |
| Unseen Task     | 4              |
| **Total**       | **12**         |

**Ranking-Based Scoring (Per Task)**

| Ranking    | Points |
| ---------- | ------ |
| Top 25%    | 4      |
| Top 25–50% | 3      |
| Top 50–75% | 2      |
| Bottom 25% | 1.5    |

**Notes:**

- Each task will be ranked independently among groups with valid final predictions, based on the designated evaluation metric.

- For incomplete tasks without valid final predictions, partial credit may be awarded based on meaningful experimental results obtained.

- Tasks with neither valid final predictions nor meaningful experimental results will receive 0 points.

## 2. General SuperAgent Design & Autonomous Development (12 Points)

| Criterion                            | Points | Description                                                                                                                                                                            |
| ------------------------------------ | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| System Design & Generality           | 5      | Quality of the SuperAgent design and implementation, including its ability to handle different classification tasks without task-specific solutions.                                   |
| Autonomous Development & Improvement | 7      | Ability of the SuperAgent to autonomously analyze tasks, select methods, conduct experiments, improve solutions based on feedback, and select final models without human intervention. |
| **Total**                            | **12** |                                                                                                                                                                                        |

## 3. Execution, Reproducibility & Report (4 Points)

| Criterion                   | Points | Description                                                                                                                 |
| --------------------------- | ------ | --------------------------------------------------------------------------------------------------------------------------- |
| Execution & Reproducibility | 2      | Successful execution, reproducibility of results, completeness of execution logs, and compliance with resource constraints. |
| Report Quality              | 2      | Clarity and completeness of the report, including system design, experiments, results, and limitations.                     |
| **Total**                   | **4**  |                                                                                                                             |

## 4. Final Presentation (12 Points)

| Criterion                                             | Points | Description                                                                                                                                                                                                          |
| ----------------------------------------------------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spoken Delivery                                       | 4      | Clarity of explanations, logical organization, speaking pace, and effectiveness in communicating technical ideas.                                                                                                    |
| Visual Delivery                                       | 3      | Clarity, readability, and organization of presentation slides; effective use of diagrams, figures, and tables to illustrate the system and experimental results.                                                     |
| Understanding of the Submitted System and Experiments | 5      | Demonstrated understanding of the system architecture, implementation, design decisions, and experimental results, as assessed through the presentation and, **where applicable**, responses to technical questions. |
| **Total**                                             | **12** |                                                                                                                                                                                                                      |
