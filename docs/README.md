# Documentation Index

Each topic has one primary owner:

- `architecture.md`: source layers, responsibilities and execution flow.
- `guides/quickstart.md`: commands and output locations.
- `guides/reproducible_environment.md`: matched torch/torchvision setup, exact environment snapshot and pinned weight provenance.
- `guides/model_cache.md`: prepare all pretrained weights/tokenizers, exact cache paths and relocation instructions.
- `guides/requirements_status.md`: one-agent design, final-only test evaluation and remaining submission evidence.
- `guides/api_usage.md`: credentials, API behavior, pricing and reconciliation operations.
- `guides/full_assignment_workflow.md`: frozen formal evaluation and submission.
- `accounting/README.md`: interpretation of the current ledger record set.
- `accounting/ledger_inventory.json`: current source-ledger hashes and arithmetic.
- `development/current_results.json`: informational model pointers, scores and runtime identities.
- `development/experiment_log.md`: all current cataloged experiments.
- `development/recommendation_review.md`: disposition of the proposed improvements.
- `development/advanced_usage.md`: implementation options and limitations.
- `report/README.md`: report version, source and build instructions.

Raw models, calls, ledgers and task inputs stay local. Documentation snapshots are read-only indexes; they are never loaded to select candidates, authorize spending or reset budgets.
