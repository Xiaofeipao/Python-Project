# AI Usage Declaration

OpenAI Codex assisted with requirements interpretation, implementation, review, debugging, testing and documentation. Development tools and runtime planning models are distinct; project API ledgers do not measure Codex token usage or costs.

Runtime planning can use the school platform's DeepSeek-V4.1-Flash or DeepSeek-V4-Pro deployments. The planner receives data summaries and validation feedback, chooses executable candidates and may propose bounded parameter or feature changes. It does not receive test scores or execute generated code. Runs with the LLM disabled or unavailable are not evidence of successful LLM planning.

Registered off-peak accounting rates per million tokens are CNY 1 input / 4 output for Flash, and CNY 4.5 input / 13.5 output for Pro. All input uses the cache-miss rate. These calculated costs are not school-platform invoices; the course must confirm the accepted accounting convention. Registries and hash-checked original evidence are under `configs/`.

Each run retains actual returned usage, requests/responses and failures in usage.jsonl, model_calls/, model_usage.json and summary.json. On 2026-11-24 the ledger was pruned at the project owner's request so that it holds only GPU runs whose every call returned usage: CPU reruns, aborted attempts and the two historical Flash timeouts with their conservative reservations were removed, and a copy of the removed records is archived outside the submission tree. The retained ledger covers fifteen GPU runs and CNY 1.319903, all accounting-complete with no reservation held and no unknown usage. A successful prediction file does not by itself establish complete accounting.

The two reported experiments are `coupon-minilm2-20261123` (11 recorded Flash calls, CNY 0.059672, held-out 0.791486) and `headlines-v6-20261124` (5 recorded Flash calls, CNY 0.027561, held-out 0.697092, runtime `0dead41e…` from commit `8ca2f16`), together CNY 0.087233. Both use the same scheme: Flash planner, 12 trials, MiniLM and feature-search enabled, three-seed validation. `headlines-v6-20261124` supersedes `headlines-minilm2-20261123` (0.670483, CNY 0.076654) because the new pairwise `char_wb` seed raises the held-out score by 2.66 pt; the cheaper 0.014231 coupon run `coupon-gpu-20261123` (0.790698) and the 0.056792 `headlines-gpu-20261123` (0.660582) remain the cheapest equivalents. The current-code coupon rerun `coupon-v6-20261124` reached 0.788727 at CNY 0.069836, slightly below the reported coupon run because the selected blend used `gpu_weight=0.55` instead of 0.275.

An accuracy-enrichment probe on the same runtime added three retained ledgers on 2026-11-23: `coupon-minilm2-20261123` (11 calls, CNY 0.059672), `headlines-minilm2-20261123` (11 calls, CNY 0.076654) and `headlines-minilm3-20261123` (11 calls, CNY 0.067790), CNY 0.204116 in total. The probe enabled the MiniLM and feature-search capabilities and scored each trial as the mean of three training seeds. One of its runs, `coupon-minilm2`, remains the reported coupon experiment; the headlines pair is now kept only as the seed-variance control (`headlines-minilm3` returns exactly 0.660582 against 0.670483). The aborted eighth-trial attempt from this probe was removed together with the ledger pruning.

A second probe implemented a five-seed final-fit ensemble (`final_fit_seeds`, commit `b8d38fb` on a separate runtime hash) and ran two more tasks: `coupon-ens-20261123` (CNY 0.025366) and `headlines-ens-20261123` (CNY 0.057801), CNY 0.083167. Averaging five refits returned 0.787544 on coupon where the best single seed reaches 0.790698, and reproduced 0.660582 exactly on headlines because all five refits are identical; it removes seed luck instead of adding accuracy. The change was reverted, so the reported experiments remain reproducible at the original runtime hash.

A planner-model swap added `coupon-pro-20261123` (DeepSeek-V4-Pro, CNY 0.122270) and `headlines-pro2-20261123` (DeepSeek-V4-Pro, CNY 0.454991), CNY 0.577261. Pro is priced from official evidence (`configs/model_registry.pro.json`, CNY 4.5 / 13.5 per million) and reproduced the Flash held-out scores exactly, at roughly eight times the planning cost. Qwen was not run: the platform only offers the rolling `Qwen` alias and `Qwen3.8-27B`, released after the 2026-10-21 course cutoff, and no published price covers the 27B alias, so a Qwen ledger could not be priced. Four search-effort rounds are also retained (`coupon-t10` CNY 0.058049, `coupon-t14r` CNY 0.065004, `headlines-t15` CNY 0.074308, `headlines-t20r` CNY 0.089579). With every retained run the ledger totals CNY 1.319903 across fifteen GPU runs, all accounting complete.
